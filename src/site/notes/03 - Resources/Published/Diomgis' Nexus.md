## 但请注意：这里的知识会过期。

这个网站讨论的主题——Agentic Engineering、LLM 模型能力、Harness 设计——**正在以月为单位迭代**。

今天的"最佳实践"，三个月后可能是"已被证伪的假设"。六个月后，它可能已经不存在了——不是因为错了，而是因为模型能力的变化让整个前提消失了。

这不是夸大。这是这个领域的正常代谢速度。

### 本站时效性公约

| 文章年龄 | 可信度 | 建议 |
|----------|--------|------|
| 0 ~ 3 个月 | 🟢 新鲜 | 正常参考 |
| 3 ~ 6 个月 | 🟡 可疑 | 谨慎参考，交叉验证 |
| 超过 6 个月 | 🔴 过期 | **不建议作为决策依据** — 领域已经跑远了 |

每篇文章顶部都标注了创建日期和最后更新日期。阅读前请先看一眼——**这个领域的真理半衰期可能比你的阅读速度还短。**

### 本站在讨论什么

- **Agentic Engineering**：从"用 agent 写代码"到"设计 agent 系统"的工程化实践
- **Harness 设计**：agent 有效性的来源不是 prompt，是环境结构
- **管线与脚本**：shell 脚本不是 agent 的工具——是管线的节点
- **工程管理**：agent 对团队结构、招聘、组织的深层影响
